🛠️ How to Run

Each file is a standalone C program. Compile and run using `gcc`:

```bash
gcc question01.c -o question01
./question01
```

Replace `question01` with the file name of the question you want to run.

📌 About

These are beginner-level practice problems solved while learning C fundamentals — arithmetic operations, conditionals, loops, and basic input/output. Shared here for practice tracking and for anyone else learning C who wants simple, clear examples to follow.
